# Hive Hostel - Smart Mess Management System

Overview
Hive Hostel - Smart Mess Management System is a web-based application designed to simplify hostel mess operations. Students can log in, select meals for each day, view their monthly bill, and make payments using a QR code. The system also includes barcode-based student verification for meal collection.

Features
- Student login using Student ID
- Weekly meal selection (Breakfast, Lunch, Dinner)
- Different menu for each day of the week
- Automatic monthly bill generation
- QR code payment support (UPI)
- Barcode/Student ID verification at the mess entrance
- Responsive and user-friendly interface

Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets (Database)

 Project Structure
```
Smart-Mess-Management/
│── index.html
│── README.md
```

How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Configure the Google Apps Script URL to enable data storage and billing features.
